# PianoCSS

Ce synthétiseur en ligne a été réalisé par Aurèle Véron-Guaitella (chef de projet), Anthony Marchiselli et Yasmine Hamadene 
pour le projet de développement qui était à rendre lors de notre dernière année de Sciences Pour l'Ingénieur - spécialité informatique, à Corte.
Le projet n'a pu être complété à temps mais il est possible de jouer du clavier à la souris avec un son basique.
